# Tableau

Store Tableau analysis assets here. Keep workbook and data-source
documentation alongside the assets so reviewers can understand their inputs
and intended use.

## Organization

- `workbooks/` — Tableau workbook files (`.twb` or packaged `.twbx`).
- `data_sources/` — data-source documentation and reusable Tableau data-source
  files.

Document required connections, tables, and refresh assumptions. Do not commit
credentials or packaged extracts containing sensitive production data.
